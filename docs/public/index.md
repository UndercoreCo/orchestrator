# Документация Undercore Orchestrator

Самостоятельный сервис для backend-разработчика и оператора VPN-инфраструктуры.
Он не заменяет пользовательский кабинет, оплату или VPN-клиент.

[Что реализовано и доступно для установки](support.md).

## Первый запуск

1. [Быстрый старт](quickstart.md): запустить пустой сервис и проверить процесс.
2. [Контракт узла](node-agent.md): понять, какой агент нужен для реального VPN.
3. [Интеграция backend](integration.md): создать, получить, продлить и отозвать доступ.
4. [Эксплуатация](operations.md): установить службу, обновить и сохранить состояние.

Наличие работающего API без совместимого узла не означает готовность выдавать VPN.
Публичного установщика агента пока нет; его выделение — следующий этап.
