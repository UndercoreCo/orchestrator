# Передача статистики трафика

Оркестратор предоставляет read-through API `POST /internal/v2/usage` для
авторизованного backend. Суммирование, история, тарифы и квоты принадлежат caller.
Оркестратор не сохраняет байты в своём журнале и не рассчитывает прирост.

Запрос: schema_version=1 и connections (1–20 элементов), каждый содержит
connection_id и device_id. Действуют общий Bearer/no-store guard и лимит тела.
Принадлежность проверяется перед I/O. Каждый результат отдельно ok/error,
недоступность не превращается в ноль. Полный контракт — contracts/openapi.json.

Успех содержит node_id, allocation_id, protocol, samples и previous. Последнее
поле содержит измерения/ошибки прежних размещений по существующему техническому
журналу привязок, без пользовательских/платёжных сущностей. Смена узла сохраняет
connection_id; allocation_id — SHA256 server identity и remote peer identity.
Разные node registry entries с прежней server identity не смешиваются молча.

Показания содержат counter_epoch, sequence, measurement_basis, started_at,
observed_at, накопленные download_bytes/upload_bytes, baseline_* и is_final/complete.
Байты — десятичные строки, направления относительно клиента. Повторы обрабатывает
caller. Нельзя складывать абсолютные значения последовательных снимков.

Amnezia-адаптер читает отдельный authenticated `/v1/clients/{id}/usage` без health
reconcile и без конфигурационных экспортов. Проверяет server_id/client_id/external_id
и структуру измерений. Старый агент или неподдерживаемый драйвер возвращает
usage_unsupported. TrustTunnel пока не объявляет поддержку счётчиков.

Чтение не продлевает срок, не включает отключённый доступ и не создаёт назначений.
Код поддерживает 64 epochs на узле и 100 прежних размещений на подключение;
превышение — явная ошибка, не усечение. Прежние привязки до этого выпуска могут
отсутствовать. Отсутствие полных данных и долговременное хранение обрабатывает caller.
Реальные VPN-движки и точность измерений требуют отдельной стендовой приёмки.
