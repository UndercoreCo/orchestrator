# Реализация, поставка и поддержка

Сверено 26.10.2026. Последний опубликованный выпуск: 0.5.1, стадия 0.x.
Наличие кода, стендовый тест и поддерживаемая публичная установка — разные статусы.

| Компонент | Реализовано | Проверено | Публичная самостоятельная поставка |
| --- | --- | --- | --- |
| Controller | API v2, CLI, SQLite, панель, install/update/backup | Контракты, lifecycle, обновление/откат; Python 3.12–3.14 в CI | Исходный архив релиза; Linux/systemd; пока не установка всей системы одной командой |
| AmneziaWG | Рабочий NodeDriver, conf/vpn/QR, control leases | Контракты и действующие узлы | Драйвер входит в controller; совместимый агент ещё не опубликован самостоятельным пакетом |
| TrustTunnel | NodeDriver и TOML-конфигурация, явный experimental_trusttunnel | Реальные TCP/UDP lifecycle-пробы на стенде | Драйвер входит в controller; managed-agent/runtime ещё не опубликованы комплектом |
| WireGuard | Политика conf/QR | Форматные тесты | Полноценного lifecycle-драйвера нет |

TrustTunnel не поддерживает control leases; нельзя включать их по аналогии с AWG.
Обычный upstream VPN-сервер без совместимого агента не является управляемым узлом.
Репозиторий vpn-node сейчас содержит README/LICENSE, а не устанавливаемый runtime.

Ограничения: один controller и локальная SQLite, один backend service token,
без изоляции независимых интеграторов, active-active HA и автоматического выбора
по скорости клиента. При потере controller AWG с короткими leases может остановить
доступ по истечении разрешения. Изменение этой политики — отдельная работа.

Формат URL API v2, schema_version, версия SQLite и версия пакета независимы.
